# Models and configuration

LocalMind has two pluggable model roles: the embedder, which turns text into vectors, and
the language model, which writes answers.

## Embedders

The default embedder is the built-in hashing embedder. It needs no downloads and works
completely offline. It hashes words and word pairs into a 512-dimensional vector, so it is
very good at matching keywords but does not understand synonyms.

For semantic search, use Ollama embeddings with `--embedder ollama`. The default embedding
model is nomic-embed-text; any Ollama embedding model such as mxbai-embed-large or
all-minilm also works via `--embed-model`. When you switch embedders, LocalMind notices
at startup and re-embeds every stored chunk automatically.

## Language models

Answers are generated by a chat model served by Ollama. The default is llama3.2, a small
model that runs well on a laptop. Larger models such as llama3.1:8b, qwen2.5 or mistral
give better answers at the cost of speed. Choose one with `--chat-model`.

If Ollama is not running, or `--llm none` is set, LocalMind answers in extractive mode.

## Common settings

Every option can be passed as a command-line flag or an environment variable:

- `--port` / `LOCALMIND_PORT` - HTTP port, default 8080.
- `--db` / `LOCALMIND_DB` - SQLite database file, default data/db/localmind.db.
- `--ingest` / `LOCALMIND_INGEST` - a file or folder to index at startup.
- `--top-k` / `LOCALMIND_TOP_K` - how many passages to retrieve, default 4.
- `--ollama-url` / `OLLAMA_URL` - where Ollama is listening, default http://127.0.0.1:11434.

Run `localmind_server --help` for the complete list.
